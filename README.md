# Kami / K Pay MVP

Kami is the financial intelligence layer, Credit Catalyst AI is the credit-analysis experience, K Pay is the universal payment layer, and Kami Card is the card interface.

## Current MVP
- Responsive financial dashboard
- Credit Catalyst AI overview and action-plan UI
- K Pay funding-source and quick-pay UI
- Kami Card controls and card visualization
- Shared black/white premium fintech design system

## Run
```bash
npm install
npm run dev
```

## Next engineering phases
1. Authentication + user profiles
2. Database schema and encrypted financial-account metadata
3. Plaid/account connectivity

5. KYC/AML and regulated payment/card provider integration
6. Real K Pay ledger and transaction orchestration
7. AI financial assistant with guarded financial-data tools

This repository contains product UI and prototype flows; it does not represent a live bank, card issuer, credit bureau, or money transmitter.
